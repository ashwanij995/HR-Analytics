# HR Analytics — Employee Attrition & Workforce Insights

## Project Overview
This project analyzes employee data to understand workforce patterns and identify factors associated with employee attrition. It uses Python, SQL, and Power BI to transform raw HR data into actionable insights.

## Objectives
- Calculate the overall employee attrition rate.
- Compare attrition across departments.
- Investigate the relationship between attrition, overtime, income, and tenure.
- Build an interactive dashboard for HR workforce analysis.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL
- Power BI Desktop

## Project Workflow
1. Loaded and inspected the HR dataset.
2. Checked for missing values, duplicates, and data type issues.
3. Performed exploratory data analysis using Python.
4. Used SQL queries to summarize employee attrition and workforce metrics.
5. Built an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Findings
- Analyzed overall employee attrition.
- Compared attrition rates across departments.
- Examined differences in attrition by overtime status.
- Compared monthly income and years at the company by attrition status.
